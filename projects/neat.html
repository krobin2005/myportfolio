Growing Neural Networks with Evolution

I learned NEAT (Stanley & Miikkulainen, 2002), tested it head-to-head against gradient descent, and taught it to my Evolutionary Computing class with a hands-on activity.

RoleResearcher & presenter
WhenOct – Nov 2026
ToolsPython, neat-python, NumPy, Colab, GitHub Actions

The idea

Gradient descent trains a network whose shape you pick, and it needs the correct answer for every example. NEAT evolves both the weights and the shape, starting from networks with no hidden neurons at all, and it only needs a score.

What I found

  • Is it a 7? On real handwritten digits, gradient descent scored 97.6% and NEAT 95.0%, but NEAT did it with no hidden neurons and 44 parameters, vs. 529 for gradient descent.
  • Balancing a pole: there's no correct push for each moment, only a score, so gradient descent can't start. NEAT balanced it for 500 steps (the max) vs. about 20 for random pushing.
  • Luck matters: rerunning the same NEAT setup with different random seeds gave anywhere from 74% to 88%, a reminder that one run isn't proof.

Teaching it

For the class activity, pairs watch NEAT grow a network, then each pair breaks one part of NEAT on purpose (no new neurons, no species, a tiny population and more), predicts what will happen, and runs it. It's a small version of the paper's own ablation study.
